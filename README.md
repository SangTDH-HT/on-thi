# Ôn thi: GDQP&AN và Triết học

App trắc nghiệm ôn thi chạy trên điện thoại, mở bằng link: https://sangtdh-ht.github.io/on-thi/

Cần mật khẩu riêng để mở. Bộ câu hỏi trong repo này đã mã hóa, không có mật khẩu thì không đọc được.

## Cài lên điện thoại

- **iPhone:** mở link bằng Safari → nút Chia sẻ → **Thêm vào MH chính** → mở icon **Ôn thi** → nhập mật khẩu.
- **Android:** mở link bằng Chrome → menu ⋮ → **Thêm vào màn hình chính** (hoặc **Cài đặt ứng dụng**) → mở icon → nhập mật khẩu.

Nhập mật khẩu một lần, máy nhớ. Sau lần mở đầu tiên, app chạy được cả khi không có mạng.

Repo này do GitHub Actions tự đẩy lên, đừng sửa tay.
